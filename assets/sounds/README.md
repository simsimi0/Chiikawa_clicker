# 클릭 반응음

각 캐릭터에 4개씩, 총 32개의 짧은 합성 보컬 반응음(WAV)입니다. 실제 애니메이션 성우 녹음이나 복제 음성이 아닙니다. 모음 포먼트와 음높이·리듬을 합성했으며, `node scripts/build-voices.cjs`로 재생성할 수 있습니다.

설정에서 음량을 조절하고 음소거할 수 있습니다. 기본적으로 소리는 꺼져 있으며 메인 화면의 소리 버튼으로도 켤 수 있습니다. 연속 클릭 시 소리가 과도하게 겹치지 않도록 이전 반응음을 멈추고 새 반응음을 재생합니다.

직접 준비한 실제 음성은 설정에서 캐릭터별 최대 4개의 파일을 선택해 현재 실행 동안 사용할 수 있습니다. 영구 교체하려면 해당 캐릭터의 WAV 파일 4개를 같은 파일명으로 바꾸세요. 후드와 기본 모습은 같은 캐릭터의 음성을 공유합니다.
